A modern, full-stack **Restaurant Management System** designed to streamline order management, table bookings, menu operations, and billing. Built with Django and Bootstrap, it offers both web access via PWA support and a standalone desktop experience using PyWebView.

---

## 🌟 Key Features

* **Order & Billing Management:** Live order tracking, bill generation, and order section handling.
* **Menu & Inventory Control:** Manage food categories, dynamic pricing, and item availability.
* **Cross-Platform Access:**
  * **Web Application:** Fully responsive design powered by Bootstrap 5.
  * **Progressive Web App (PWA):** Mobile-friendly offline capabilities and app-like installability.
  * **Desktop App:** Embedded desktop client powered by **PyWebView**.
* **Database Integration:** Reliable data storage powered by PostgreSQL.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
* **Database:** PostgreSQL
* **Desktop Wrapper:** PyWebView
* **Mobile Capabilities:** Progressive Web App (PWA)
